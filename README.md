---

## How I built it

Pure HTML/CSS/JS. No React, no Tailwind, no template.

The design is inspired by editorial print — black borders, yellow accent (`#FFD600`), white background, and [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) + [Space Mono](https://fonts.google.com/specimen/Space+Mono) as the only two fonts. The goal was something that felt like *mine*, not like every other dark-background portfolio you've seen.

All data (projects, writings, awards, experience) is hardcoded as JS arrays and rendered into the DOM no fetch, no JSON files, no backend.

Hosted on Vercel.
